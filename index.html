Como descobrir o grau?

Você precisa somar os expoentes das variáveis.

4x²y³

x tem expoente 2.
y tem expoente 3.

2 + 3 = 5

Portanto, 4x²y³ é de 5º grau.

Exemplos

x → 1º grau

x² → 2º grau

3xy → 2º grau

2x²y → 3º grau

a³b² → 5º grau

x²y³z → 6º grau
